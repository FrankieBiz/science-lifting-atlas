# SBLA-012 usability-gate decision

**Decision date:** 2026-09-24

**Authority:** human owner, directly in the project task

**Scope:** SBLA-012 only

The owner directed Codex to remove the planned 3–5 participant requirement.
SBLA-012 will proceed without recruitment or simulated participant findings.
The earlier formative plan and report remain in the repository as historical
records, clearly marked superseded.

The replacement gate is a reproducible static acceptance check: exercise the
local prototype's find, understand, verify, share, and methodology routes;
check keyboard access, mobile reflow, reduced motion, stable links, and the
fail-closed publication boundary; run the repository's required checks; obtain
one independent acceptance review; then ask the owner to approve the visual
direction. The acceptance record must distinguish browser behavior from human
comprehension. It must not claim that users found the interface understandable
without participant observations.

This decision changes no scientific evidence, citation, license, publication,
or anatomy-quality gate. In particular, the 2026-09-17 production hold on
SBLA-013 through SBLA-015 remains active. It also leaves the separate beta
usability work in the later release phase unchanged.
