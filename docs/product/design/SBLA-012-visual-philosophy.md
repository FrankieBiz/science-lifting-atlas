# Atlas — clarity through restraint

The owner authorized a substantial Apple-inspired visual redesign on
2026-09-24. This direction supersedes Applied Strength Editorial for SBLA-012.
The design uses Apple's principles of hierarchy, legibility, and considered
spacing while retaining the atlas's own identity and scientific boundaries.

## Visual system

- White `#ffffff` is the reading surface; fog `#f5f5f7` groups related records.
- Graphite `#1d1d1f` carries primary text; gray `#626268` carries secondary text.
- Blue `#0066cc` identifies links and actions. Muted rose `#a83d4e` identifies
  the anatomy category, never evidence certainty.
- Native system sans typography leads throughout. Display headlines use tight
  but readable spacing, with no decorative serif emphasis. Body copy remains
  at a comfortable measure and at least 16 px in reading areas.
- A compact, translucent header stays available while reading. Primary actions
  use rounded blue buttons; supporting navigation uses quiet text links.
- Large radii define media surfaces and collections; evidence disclosures use
  smaller radii so their purpose and hierarchy remain distinct.

## Composition

The homepage pairs a clear title and action with one large, dark anatomical
study plate. A compact status row explains the current collection. The next
section exposes the muscle and both movement records directly. The evidence
chain and methodology form a quieter, progressively deeper reading path.

```
[ Atlas identity                 Explore / Evidence / How it works ]
[ Clear promise + action          Anatomical study plate           ]
[ Collection status               Current structure label          ]
[ Explore the first chapter: muscle / bench press / cable fly       ]
[ From anatomy to evidence: structure -> movement -> source trail   ]
[ Practical language / visible uncertainty / exact source trails    ]
```

Record pages bring the name, scope, takeaway navigation, and visual orientation
into one opening section. Evidence statements stay intact. Source records use
quiet research-document typography, with a compact metadata panel and generous
reading space. Methodology uses the same surfaces and hierarchy.

The anatomy plate is the single dramatic visual. Other areas remain restrained:
no decorative grids, oversized background numbers, fake viewer controls, or
unnecessary uppercase labels. Motion only responds to interaction. The site
remains fully usable without JavaScript.

## Preserved boundaries

The approved BodyParts3D plate remains an attributed static evaluation asset.
This redesign does not create new anatomy, modify meshes, or lift the production
hold. No scientific claim or extraction is rewritten. Prototype warnings,
source qualifiers, certainty labels, exact locators, and publication gates stay
visible and functional.

Keyboard focus, reduced motion, narrow reflow, clear link names, semantic
headings, and non-color status labels are required. Validate all five page
archetypes visually at desktop and phone widths and run the repository's
required checks before committing. Browser checks prove interaction behavior;
they do not constitute independent review or owner visual approval.
