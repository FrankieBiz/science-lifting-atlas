# Anatomy explorer back-view poster

- **Source:** the project's derived BodyParts3D model at
  `assets/derived/bodyparts3d/anatomy-explorer.glb`.
- **Method:** captured from the interactive anatomy canvas with the back view
  selected and a transparent WebGL background. The back camera is positioned
  at `(0, 0.88, -3.45)`. The poster is not hand-cropped or retouched.
