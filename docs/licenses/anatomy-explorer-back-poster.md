# Anatomy explorer back-view poster

- **Source:** the project's derived BodyParts3D model at
  `assets/derived/bodyparts3d/anatomy-explorer.glb`.
- **Method:** captured by `pnpm assets:capture-posters` from the interactive
  anatomy canvas with the back view selected and a transparent WebGL
  background. The back camera is positioned at `(0, 0.88, -3.45)`. The canvas
  is rendered at 1.5× the output size and downscaled in the browser to
  3448×2688, four times the 862×672 frame the plate and hotspot points are
  measured against. The front poster, `anatomy-explorer-poster.png`, is
  captured the same way from the front view. Neither poster is hand-cropped or
  retouched; pages receive WebP variants generated at build time.
