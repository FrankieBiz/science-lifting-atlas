# Homepage interactive anatomy

The owner requested the attractive model and interactive elements on the
website itself. This refinement promotes anatomy exploration into the main
homepage in both normal and local review builds. Evidence publication gates
still control record links and scientific claims; the anatomy workspace is a
visual reference, not acceptance of the full production milestone.

Use the same pinned BodyParts3D adaptation, with the 139 approved muscle
meshes and body surface. Simplify deterministically with pinned meshoptimizer
to keep the GLB below 3 MB. Preserve exact source IDs, approved entity mapping,
source hashes, attribution, and known coverage gaps. The five unmapped targets
must not appear as selectable muscles.

The homepage opens with a compact title above a large anatomy workspace.
White and pale gray controls surround a dark blue-gray stage. System sans
typography and restrained rose/blue materials follow the owner's Apple-style
direction. A searchable muscle list selects the figure and updates a focused
panel. Clicking a mapped muscle on the model selects the same item. Front,
back, zoom, reset, and isolate controls are visible and keyboard accessible.
Only pectoralis major links to reviewed-content preview, and only when the
local preview flag allows that route. Other selections show anatomy identity
without invented training advice.

Load the interactive model when the workspace enters the viewport, keeping
the static image and text list as the no-JavaScript path. A request failure
offers retry. On small screens the list becomes a compact searchable selector
above the figure. Check rendered readiness, search/selection, camera controls,
isolation, fallback, reflow, and production evidence boundaries. Commit and
push all work with an honest handoff as requested by the owner.
